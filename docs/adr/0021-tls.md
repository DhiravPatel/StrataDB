# ADR-0021: TLS for the HTTP listener

- **Status:** Accepted
- **Spec references:** §18.5, §18.9

## Decision
rustls 0.23 (memory-safe) with the `ring` provider; TLS 1.2 + 1.3 with
rustls' safe defaults (AEAD-only suites, no renegotiation, no TLS ≤ 1.1).
`aws-lc-rs` was not chosen because it needs a C/cmake toolchain and is
larger. Certificates/keys are PEM files (`--tls-cert`, `--tls-key`); a
mismatched pair is rejected at start-up. Handshakes run in separate tasks
with a 10 s timeout and ≤ 256 concurrent handshakes (excess connections are
dropped), so slow clients cannot block the accept loop. Binding a
non-loopback address is allowed only with TLS (or the explicit insecure flag).

Not yet: certificate hot-reload (restart to rotate), mTLS/client
certificates, OCSP stapling.

## Evidence
`apps/stratadb-server/tests/tls.rs` (real handshake against a generated cert,
plaintext rejected, key/cert mismatch rejected); manual curl smoke test.
