# Security policy

StrataDB is pre-alpha and has **no network listener, authentication, or TLS
yet**; it must not be exposed to untrusted users. Security is release-blocking
(spec §18); see [THREAT_MODEL.md](THREAT_MODEL.md).

## Reporting a vulnerability
A private reporting channel has **not been configured yet** (maintainer
action required before any public release: e.g. GitHub private vulnerability
reporting). Until then, do not file public issues for vulnerabilities.

Targets once the channel exists: acknowledge within 3 business days, triage
within 10, coordinated disclosure after a fix or 90 days.

## Supported versions
None yet (pre-release).
